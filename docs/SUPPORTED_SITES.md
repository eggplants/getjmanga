## URL formats

| Extractor | URL |
| --- | --- |
| `gigaviewer` | `https://<host>/episode/<id>` (also `/magazine/`, `/volume/`) |
| | `https://<host>/series/<id>/first_episode` |
| | `https://<host>/rss/series/<id>` -- every episode in the feed |
| `comici` | `https://<host>/episodes/<id>` |
| | `https://<host>/series/<id>`, `/new` or `/<page>` -- the whole series, oldest first |
| | `https://<host>/series/<id>/rss` -- the latest episodes, newest first |
